Welcome to User Management App

A full-stack CRUD application built with HTML, CSS, JavaScript, and REST API.

👥 View All Users ➕ Create New User

⚡ Create

Register new users with name, email, and password via HTTP POST.

📋 Read

Fetch and display all registered users dynamically via HTTP GET.

✏️ Update

Fetch single user data via query params and modify via HTTP PUT.

🗑️ Delete

Remove user records instantly from database via HTTP DELETE.
